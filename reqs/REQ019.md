VFS 接口

+ vfs_resolver: VFSResolver     根据 path 自动创建 VFS 并挂载
    - 对于 git , 根据 branch | tag | hash 获得 tree 构造 vfs 
        - 名字为 git:[branch | tag | hash]
    - 对于 文件容器（tree-sitter） 
        - 名字为 tree-sitter:[path]
    - 对于 localfs，根据配置文件挂载
        - 名字为 local:[path]
        - 此类型可作为入口（根文件系统）
    - 对于 git-repo ，根据配置文件挂载
        - 名字为 repo:[path] , 这里 path 是 .git 所在的路径
        - 此类型可作为入口（根文件系统）
        - git-repo 是 git + localfs 两个的组合，如果继续直接访问 文件路径，则为 localfs 访问
            - 如果添加 .git/hash 访问，则为 git tree view
            - 因为在实际文件系统中 .git 是 git repo 的关键文件，不应直接访问。
    - 参数为 文件路径，根据是否存在 .git 判断是 localfs | git-repo

+ path_resolver: PathResolver   根据路径，解析出 VFS 和 余下的路径剩余

- resolve_path(path: PurePosixPath) -> (vfs: VFS, path: PurePosixPath)
- mount (path： PurePosixPath)
- unmount (path： PurePosixPath)
- mounts () -> list[PurePosixPath]

- info(path) -> dict
- list (path, option：dict) -> list[PurePosixPath]  , option 为排序、过滤方式
- get (path) -> bytes
- name () -> str
    - VFS 的名字
- readonly() -> bool
- patch (path, range: (int, int), bytes, session_id: Optional[str]) -> op_id: str   
    - 以 bytes 为操作单位，patch 更接近 ot 的变更方式
    - patch 并不会直接修改文件，而是记录在文件根目录的编辑日志
    - 允许多个编辑事务性提交
    - 编辑日志为 jsonl 格式
    - 当文件被修改时，会发出通知（那部分变更）
    - 需要有服务 watch 文件才会发出通知
    - 可以考虑在内存中维护一个 git tree.

- put(path, bytes)
    - 允许为 '' ，即语义上是 touch
    
- commit (op_id: Optional[str], session_id: Optional[str]) -> Tuple[bool, str]
    - 应用编辑日志到实际文件，同时清空编辑日志
    - 如果给出 session_id ，则 op_id 可以传 '' 或 None
    - 如果未给出任何参数，为提交所有已经存在的 patch
    - 如果 op_id 属于某个 session , 则会提交 session 中的全部记录

- abort (op_id: Optional[str], session_id: Optional[str]) -> Tuple[bool, str]
    - 放弃一个 session 下的所有 patch ，并清空编辑日志
    - 如果 op_id 属于某个 session , 则会放弃 session 中的全部记录


## Web API

VFS 接口需要适配一个 Web API , 类似 FTP 的 WebAPI ，允许列出目录下文件...(只读访问)

    - Web API 为只读访问

## Edit API

VFS 接口中，能够启用异步的，均应启用异步
存在 patch 的记录文件在 入口（根文件系统）管理的 localfs 文件下的 .patches 文件中
- 因为这个存在，所有的 mounted fs 均需要持有 EditManager 的引用（用于转发 edit 请求）
- 仅 root fs 会构造 EditManager
- get 时，需要从编辑记录中读取，并应用
- 对于 在只读文件系统中的 file , patch 一样成立，但是提交会失败
